## Becoming a Good Software Developer

The session emphasized that becoming a good programmer is a long-term process based on study, practice, experience, and consistent habits.

### 1. Build Good Habits

Small and consistent improvements can compound into significant results over time.

### 2. Develop Interest

- Maintain interest in programming.
- Make learning enjoyable.
- Sustain interest when pursuing a career in software engineering.

### 3. Learn by Doing

The session emphasized learning through practice:

- Write lots of code.
- Learn through failure and success.
- Work on progressively harder problems.
- Apply theoretical knowledge through practical work.

### 4. Read and Discuss Code

- Read code regularly.
- Study code from libraries and popular projects.
- Participate in code reviews.
- Discuss programming with other developers.
- Learn from mentors and experienced programmers.

### 5. Work on Projects

Project-based learning was encouraged:

- Work on projects independently.
- Take on challenging projects.
- Work with other developers.
- Study and understand code written by others.
- Learn how to maintain and fix existing programs.

### 6. Learn Multiple Programming Languages

The session encouraged learning multiple programming languages and understanding different programming paradigms.

Examples mentioned include:

- C
- Java
- C++
- TypeScript
- Lisp
- ML
- Haskell
- Clojure
- Rust
- Go

## Web Request Flow – Introduction

The Kick-off also introduced the question of what happens when visiting a website such as `google.com`.

The basic components presented were:

```text
Client Device → Internet → Backend Servers
```

This serves as an introduction to understanding how web applications communicate between the client and backend.

## Key Takeaways

- Software development requires continuous learning and practice.
- Consistent habits contribute to long-term improvement.
- Learning by doing is an important part of becoming a better programmer.
- Reading and discussing code helps improve programming skills.
- Working on both individual and collaborative projects provides practical experience.
- Learning multiple programming languages helps expose developers to different programming approaches.
- Professional skills such as communication, teamwork, adaptability, and problem solving are part of the training journey.
- The training combines technical development with workplace and professional skills.
