# Web Essentials – HTML, CSS & Responsive Web Design

This section covers the fundamentals of building and styling web pages using **HTML, CSS, and Responsive Web Design (RWD)**.

## HTML

HTML (HyperText Markup Language) is used to define the structure and content of web pages.

### Topics Covered
- HTML document structure
- `<!DOCTYPE html>`
- `<html>`, `<head>`, `<title>`, and `<body>`
- Character encoding using UTF-8
- Viewport meta tag
- Headings and paragraphs
- `<strong>`, `<em>`, and `<br>`
- Ordered and unordered lists
- Links using `<a>`
- Images using `<img>` and `alt`
- Semantic HTML
- `<header>`, `<main>`, `<section>`, and `<footer>`

The training also included creating a basic portfolio/resume layout using HTML. 

## CSS

CSS (Cascading Style Sheets) is used to style and control the appearance and layout of HTML elements.

### Types of CSS
- Inline CSS
- Internal CSS
- External CSS

External CSS was emphasized for real-world projects because it keeps structure and styling separated.

### CSS Selectors
- Element selectors
- Class selectors
- ID selectors
- Universal selector

### Basic Styling
- `color`
- `background-color`
- `font-size`
- `margin`
- `padding`
- `border`
- `width`
- `height`
- `border-radius`
- `box-shadow`
- `max-width`
- `display`

## CSS Box Model

The CSS box model consists of:

1. Content
2. Padding
3. Border
4. Margin

Understanding the box model is important for controlling spacing and sizing of elements.

## Flexbox

Flexbox is a CSS layout system used to arrange elements efficiently in rows or columns.

### Important Properties
- `display: flex`
- `flex-direction`
- `justify-content`
- `align-items`
- `flex-wrap`
- `gap`
- `align-content`

Flexbox is useful for navigation bars, responsive layouts, card arrangements, alignment, and distributing space between elements. 

## CSS Grid

CSS Grid is a two-dimensional layout system that organizes content into rows and columns.

### Grid vs Flexbox
- **Grid:** Best suited for two-dimensional layouts involving rows and columns.
- **Flexbox:** Best suited for one-dimensional layouts involving a row or a column.

Grid is particularly useful for dashboards, card layouts, and complex responsive page structures.

## Responsive Web Design

Responsive Web Design (RWD) ensures that websites adapt properly to different screen sizes, including mobile phones, tablets, laptops, and desktops.

### Key RWD Techniques
- Viewport meta tag
- Fluid layouts
- Media queries
- Flexible images
- Mobile-first design

Example:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Media queries can be used to apply different styles depending on screen width.
